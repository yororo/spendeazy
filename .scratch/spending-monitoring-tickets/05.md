## What to build

Users assign Categories in a compact phone interaction, retain full corrections, and explicitly advance through included Unmapped Transactions.

Scope: parent User Stories 11, 12, 16, 26; ID-5.

## Acceptance criteria

- [ ] Provide compact Category assignment while preserving full description, date, amount, and Category corrections in Categorize.
- [ ] Do not apply an assignment merely on Category selection; Apply & next explicitly saves and advances to the next included Unmapped row in the selected order using stable row identities.
- [ ] When no included Unmapped row remains, show completion feedback and the normal route to Review; do not automatically commit.
- [ ] Eligible expense exclusion/re-inclusion remains reversible in Categorize and updates summaries; ineligible payment/credit activity remains ineligible.
- [ ] Failures retain entered values and editor position; selected order and filters remain usable across repeated assignments.
- [ ] Verify 320px/390px phones, desktop, keyboard/focus behavior, full corrections, exclusion/re-inclusion, next-row skipping, and coexistence with existing Category Suggestions. Avoid changing Rule semantics in this slice.
