## What to build

Users categorize repeated descriptions in one statement through a controlled preview without overwriting previously reviewed work.

Scope: parent User Stories 13–15; ID-5.

## Acceptance criteria

- [ ] Default candidates to included Unmapped expense rows with the same normalized full description in the current Statement Import.
- [ ] Normalize case and whitespace using existing matching semantics; retain punctuation and do not infer merchant identity or search other imports.
- [ ] Preview the affected rows and count, permit deselection, and apply one Category only to the selected rows.
- [ ] Preserve existing assignments unless explicitly selected for replacement; default selection never changes or re-includes excluded rows.
- [ ] Bulk assignment is Manual and temporary; it never implicitly creates a persistent Category Rule or rewrites reviewed assignments.
- [ ] Test normalized repeats, punctuation distinctions, deselection, explicit replacement, excluded rows, empty selection, and consistent summaries through Review and commit.
