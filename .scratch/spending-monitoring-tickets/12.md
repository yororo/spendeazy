## What to build

Users inspect monthly trends and daily spikes through readable touch/keyboard details and a compact Category selector without silently changing their Reporting Period.

Scope: parent User Stories 46–49; ID-9.

## Acceptance criteria

- [ ] Default comparisons to the three highest-spending available Categories for the chart range, or all if fewer; provide a compact selector for changing/adding Categories.
- [ ] Keep stable Category Colors across views and distinguish Categories that share a color through labels/other cues; use readable month/year labels.
- [ ] Touch, pointer, and keyboard inspection opens equivalent details with date/month, totals, Category breakdown, Budget states, contributing Transactions, and contextual actions.
- [ ] Inspection alone preserves Reporting Period; only explicit View this month changes it. Subsequent Transaction actions carry inspected context and dismissal restores focus.
- [ ] Preserve accessible tables and nonvisual detail access; aria-hidden charts must not be the sole interactive path, and overlays/tab bars leave controls reachable.
- [ ] Explain recorded daily-spike contributions even without enough historical data for a potential-pattern signal; chart inspection does not depend on that signal engine.
- [ ] Verify default/fewer Categories, selector updates, duplicate colors, keyboard/touch interaction, month navigation, focus, readable phone layouts, desktop behavior, and light/dark tokens.

## Implementation and validation guardrails

Use existing feature/page/service and isolated browser → API → PostgreSQL test seams. Each slice owns its meaningful regression tests and runs required owning-project checks plus the repository-required isolated end-to-end suite before completion. Preserve accepted Rule-storage/reconciliation ADRs, frontend feature boundaries, existing authorization and atomic import behavior; validate both sides of any discovered API contract adjustment. No new test framework, Review editing, numerical forecasts, automatic Budget changes, or private financial fixtures.
