# Invite Codes for Shared Space Invitations

Shared Space Invitations use codes that a sender shares directly, replacing recipient email targeting, verified-email matching, invitation email delivery, and public email-link actions in [the original Shared Spaces decision](0002-personal-and-shared-spaces.md). Any eligible signed-in User who has a valid code may save the invitation in Sharing and explicitly join. This removes the invitation's dependency on email delivery while retaining independent sign-in identities and atomic Shared Space creation. Shared Space archive notifications are in-app only, so sharing no longer depends on an external email provider.

A sender may have one pending invitation, can view and copy its code while active, and can rotate or revoke it. A code expires after seven days, is consumed by joining, and must be difficult to guess. Entering a code saves a personal claim without reserving membership; declining removes only that claim. Rotation invalidates the old code and all claims made through it. Joining still requires both Users to be eligible and invalidates competing invitations. The Sharing page is the place to manage outgoing codes and saved incoming invitations. Existing email invitations need no rollout conversion because the application has not yet been deployed to users.
