# Cursor Cloud environment (separate image)

Node.js 24.11.1 is installed at `/usr/local/lib/nodejs`; prepend its `bin` to `PATH` if the shell selects another version. The Android SDK is at `/opt/android-sdk`; set `ANDROID_HOME` and `ANDROID_SDK_ROOT` accordingly. The `spendeazy` AVD uses a Google Play image. This host requires software emulation (no KVM); boot can take about ten minutes. Confirm `adb shell getprop sys.boot_completed` prints `1`. Use the same [local runbook](../testing/local-testing.md) once Docker and the emulator are available; the emulator reaches the host API at `10.0.2.2`.

The image startup script may already be running PostgreSQL and the API against a database other than the runbook Compose database. Point `api/.env.local` at Compose, stop that API, then follow [daily startup](../testing/local-testing.md#daily-startup). Copy Clerk and Google values from the environment when they are present. The first launch can sit on a blank dev-client screen or an "isn't responding" dialog before the sign-in screen; that screen completes startup until a human finishes Google sign-in.
