# Spendeazy glossary

Spendeazy is a personal-finance app for recording positive Expenses, reviewing statement Transactions and planning spending with Category Budgets. Financial data is separate within Personal and Shared Spaces.

Use this file as the single domain vocabulary for both the native mobile app and API. See [the mobile Expense and API specification](docs/specifications/mobile-expense-domain-api.md) for detailed behavior and target contracts.
